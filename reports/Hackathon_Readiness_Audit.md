## Scientific Audit
- **Host-Star Leakage Prevention:** Ensured via custom `GroupKFold` by `target_id` in `test_train.py`.
- **Group-Aware Validation:** Validated dynamically during dataset splits.
- **PR-AUC Metric:** Primary metric generated by the training pipeline; ROC-AUC relegated to secondary.
- **No Fabricated Labels:** Model training specifically checks for truth datasets. If a real labeled distribution is not supplied, it safely degrades.
- **No Fabricated Metrics:** Physical properties preserve `NaN`/`None` when astrophysical input parameters (like Stellar Radius) are omitted.
- **Explicit Missing Values:** Upgraded the JSON serialization boundaries across Pydantic to strictly allow `dict[str, float \| None]` routing missing `NaN` values securely into dashboard requests.
- **PLATO Synthetic Framing:** Evaluated heavily through `PLATO_SYNTHETIC` simulation tests.

## Performance Limitations & Constraints
- **BLS Runtime:** Astropy's Box Least Squares algorithm is CPU-intensive. While FastAPI inherently executes standard `def` routes on a threadpool to prevent blocking the event loop, high-cadence short-period scans remain computationally bottlenecked.
- **Catalog Lookup Scalability:** `TicCtlCatalog` uses standard Python `csv.DictReader` to lazily stream rows. While memory-safe (preventing RAM OOM crashes on 9.5GB tables), it forces an **O(N)** sequential read per `find_tic` query, which scales extremely poorly for high-throughput pipelines. A Postgres `pg_trgm` or B-Tree index cache layer is required for production.
- **Outlier Clipping Collision:** Standard `lightkurve.remove_outliers` trims points heavily above/below a set sigma. I explicitly bypassed aggressively erasing transits by ensuring `sigma_clip` dynamically calibrates to real noise bounds.
